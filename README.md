## 🚀 Яндекс.Практикум - Проектная деятельность

### ▶️ Starlink — Telegram-бот для поддержки сотрудников
- 📝 *Описание:* Командный проект от Яндекс.Практикума. Адаптивный шаблон, OAuth2 авторизация администратора, интеграция JS-графиков, обработка ошибок, настройка деплоя, Docker-контейнеризация, CI/CD через GitHub Actions.
- ▶ Командный проект от реального заказчика Яндекс.Практикума
- На реализацию проекта было выделено 5 недель.
- Моя часть работы:
- Сверстал адаптивный шаблонный дизайн близкий к брендбуку компании на Bootstrap с
Jinja2Templates.
- Внедрил систему авторизации авторизация админа с логином и паролем, реализовано с
помощью OAuth2PasswordBearerWithCookie.
- Подключил css и js-скрипты и измененил их с учетом цветовой гаммы сайта заказчика.
- Встроил графики на JavaScript привязанные к изменяемым данным.
- Настроил сервер для деплоя.
- Собрал контейнеры на Docker и Docker-compouse.
- Решил проблемы с отображением статики https.
- Разработал обработку ошибок на уровне приложения fastapi и создал шаблоны html страниц
для ошибок.
- Создал секреты и добавил их в github actions.
- Реализовал создание .env файла в момент сборки и деплое проекта из секретов хранящихся на
github.
- Занимался деплоем проекта на сервер. Написал workflows для CI/CD.
• Активно принимал участие во всех со звонах и обсуждениях проекта, предлагал идеи.
- 🛠 *Стек:* `Python 3.12` `FastAPI` `SQLAlchemy` `PostgreSQL` `OAuth2` `Docker` `GitHub Actions` `Jinja2` `PyTelegramBotAPI`
- 🔗 *GitHub:* [Starlink](https://github.com/Studio-Yandex-Practicum/Starlink_team2)
